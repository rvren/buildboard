The canvas and the code are the same thing.

macOS says the app is “damaged” or from an unidentified developer?

That's expected for a free, un-notarized app — it's ad-hoc signed and safe; macOS just quarantines anything downloaded from the web. Drag BuildBoard into your Applications folder first, then clear the quarantine flag once in Terminal:

xattr -cr /Applications/BuildBoard.app

Apple Silicon (M1/M2/M3): run the command above — it's required, because macOS won't launch a quarantined Apple-Silicon app until the flag is cleared. Then open it normally. (Alternatively: right-click the app → Open, or allow it under System Settings → Privacy & Security → Open Anyway.)
